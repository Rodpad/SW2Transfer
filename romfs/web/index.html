Help

Uploading

  1. Click folders to open them; the path at the top jumps back up. Uploads go into the folder you are in.
  2. Upload files picks one or more files. Upload folder picks a whole folder, subfolders included.
  3. You can also drag files and folders (several at once) anywhere onto the page.
  4. Up to 4 files upload at once, one connection each; a big file on its own is split into chunks that all the connections send together.
  5. If a file is already on the Switch, you are asked once, when its turn comes: Overwrite all, Skip all or Cancel transfer (which stops this upload and removes the files it had started).

Downloading and managing files

  • Click a file to tick it. Download on its row saves it: the chunks are put together in the browser, then saved to your Downloads.
  • Files over 3.5 GB download over a single connection.
  • Each file has Download, and every row has Rename and Delete (deleting a folder removes everything in it). New folder makes a folder here.
  • Tick the boxes to work on several items: Download selected saves them (see below), Copy to… and Move to… let you click through folders to pick the destination, Delete removes them. The box in the bar ticks everything in the folder.
  • Password: press − on the Switch to set one. This page then asks for it, and keeps you signed in for 12 hours; Sign out ends it early.
  • Cancel all (under Transfers) stops every transfer and copy, from any device. Unfinished uploads and copies are deleted from the Switch. On the Switch, press X twice; in a terminal, sw2xfer.py cancel.
  • Copies run on the Switch and show their progress under Transfers. A copy into the same folder is named “name copy”. Moves are instant and never replace an existing item.
  • Download selected saves one ticked file as it is; several items, or folders (with everything in them), come as one transfer.zip. A file's own Download button always saves just that file. A zip is limited to 1.5 GB, since the browser builds it in memory; past that the page offers to download the files one by one instead (into Downloads, without their folders), or, when the selection has more than one folder, points you to the command-line client (it keeps folders and has no limit) or FTP.

Speed settings

Connections is how many connections are used in all: up to 4 files move at once, and spare connections help big files. Chunk is the piece each one moves at a time. 8 connections with 2 MB chunks were fastest in tests.

Command-line client (Mac, Windows, Linux)

Needs Python 3. Download sw2xfer.py, then run it from the folder you saved it in. The last path is always the destination.

Options: -n 8 connections, --chunk 2M chunk size, bench /path/test.bin measures upload and download speed (the test file is deleted afterwards).

FTP

Any FTP client works (FileZilla, Cyberduck, WinSCP, lftp…): server , port 6700, passive mode. Without a password any user name and password are accepted; with one, use the SW2Transfer password with any user name (FTP sends it unencrypted). Clients that move several files at once, or one file in parts (lftp pget), get the multi-connection speed too.
