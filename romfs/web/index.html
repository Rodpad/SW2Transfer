Help

Uploading

  1. Click folders to open them; the path at the top jumps back up. Uploads go into the folder you are in.
  2. Upload files picks one or more files. Upload folder picks a whole folder, subfolders included.
  3. You can also drag files and folders (several at once) anywhere onto the page.
  4. Up to 4 files upload at once, one connection each; a big file on its own is split into chunks that all the connections send together.

Downloading and managing files

  • Click a file to download it. The chunks are put together in the browser, then saved to your Downloads.
  • Files over 3.5 GB download over a single connection.
  • Each row has Rename and Delete (deleting a folder removes everything in it). New folder makes a folder here.
  • Tick the boxes to work on several items: Download saves the ticked files, Copy to… and Move to… let you click through folders to pick the destination, Delete removes them. The box in the bar ticks everything in the folder.
  • Password: press − on the Switch to set one. This page then asks for it, and keeps you signed in for 12 hours; Sign out ends it early.
  • Cancel all (under Transfers) stops every transfer and copy, from any device. Unfinished uploads and copies are deleted from the Switch. On the Switch, press X twice; in a terminal, sw2xfer.py cancel.
  • Copies run on the Switch and show their progress under Transfers. A copy into the same folder is named “name copy”. Moves are instant and never replace an existing item.
  • To download a whole folder to your computer, use the command-line client below.

Speed settings

Connections is how many connections share each file; Chunk is the piece each one moves at a time. 8 connections with 2 MB chunks were fastest in tests; more than 8 tends to slow downloads.

Command-line client (Mac, Windows, Linux)

Needs Python 3. Download sw2xfer.py, then run it from the folder you saved it in. The last path is always the destination.

Options: -n 8 connections, --chunk 2M chunk size, bench /path/test.bin measures upload and download speed (the test file is deleted afterwards).
